## 따라간 순서

1. 행사 계획에서 토리에게 "11월 28일부터 29일까지 1박 2일로 가평이고, 30명 정도 예상해요. 참가비는 1인 45,000원 받을 생각이에요."라고 보냄 → 「이 조건으로 초안 만들기」로 13단계 계획 생성
2. 할 일이 없는 앞 두 단계(담당 인원 배치, 장소·교통 알아보기)를 빼서 첫 단계를 「사전 수요 조사」로 둠
3. 「운영 시작」 → 첫 단계의 공지에 토리 초안이 들어옴
4. 본문을 고쳐 저장 → 승인 → 「문구 복사」 → 「게시했습니다」
5. 첫 단계가 끝나 「모집 공지」가 현재 단계가 됨 → 그 공지에 토리 초안이 들어옴
6. 「초안 다시 받기」를 누르고, 초안이 오는 동안 직접 글을 씀 → 저장하면 충돌 안내 → 두 버튼 각각 확인
7. 승인한 뒤 「내용 고치기」로 고침 → 다시 승인 대기로 돌아감
