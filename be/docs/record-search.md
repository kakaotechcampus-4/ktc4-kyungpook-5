# 자료함 통합 검색

`GET /api/v1/records/search?clubId={id}&query={text}&page=1&size=20`은 로그인 계정이 속한 동아리 자료를 검색한다. `query`는 공백을 제거한 뒤 비어 있지 않아야 하며 입력 길이는 최대 200자다. 페이지와 크기는 각각 1 이상이며 크기는 최대 100이다.

파일명과 파싱한 본문은 해당 소속 전체 문서를 대상으로 대소문자 구분 없이 부분 일치 검색한다. 파싱은 성공했지만 색인되지 않은 문서도 본문 검색에 포함한다. 파싱이 실패한 문서는 파일명만 검색할 수 있다. `%`와 `_`는 와일드카드가 아닌 문자로 검색한다.

색인된 문서는 기존 AI 공개 검색과 동아리 범위를 고정한 pgvector port로 최대 50개의 유사 청크를 찾는다. 하나의 문서에 여러 청크가 있으면 문서 하나로 합친다. 이 상위 청크 후보는 모든 관련 문서를 빠짐없이 찾는다는 보장이 없으며 `semanticScore`는 확률이나 관련성 판정이 아닌 코사인 유사도다. 검색 결과는 파일명 일치, 본문 일치, 의미 검색 후보 순이고 그 안에서 점수·파일명·ID로 정렬한다. 내용이나 모델 결과가 달라지면 별도 페이지 요청 사이에 목록이 변할 수 있다.

응답 `data.items`에는 기존 자료 메타데이터, `matchTypes`, 최대 3개의 원문 발췌와 위치, 선택적 `semanticScore`가 있다. `meta`는 병합된 현재 결과의 페이지·크기·전체 수다. `indexedCount`, `unindexedCount`, `semanticCandidateLimit`은 검색 범위를 보여준다. `semanticStatus`는 `AVAILABLE`(의미 검색 완료), `UNAVAILABLE`(AI 오류로 의미 검색 실패, 키워드 결과는 유지), `NO_INDEXED_RECORDS`(색인 자료가 없어 호출하지 않음)이다. DB 오류는 성공 또는 빈 결과로 바꾸지 않는다. 원본 다운로드는 기존 인증 경로 `GET /api/v1/records/{id}/file`을 사용한다.
