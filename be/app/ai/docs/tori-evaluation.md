# 토리 요청 분류 점검

## 2026-10-30 합성 실호출

기준 `5afaecc` 위 토리 분류 추가. GPT-5.6 Luna의 공개 구조화 출력으로 독립 문장 6개를 각 1회 호출했다. `지난 MT 예산 자료 찾아줘`는 record_search, `이번 주 내 할 일 보여줘`는 task_list/self/task와 2026-10-26~11-01, `행사 계획하고 싶어`는 event_planning, `회의 시작할래`는 meeting, `내일 알림 예약해줘`와 `안녕`은 unsupported였다. 기준일 2026-10-30, 시간대 Asia/Seoul이며 실제 사용자 데이터·DB 조회·화면 이동·예약은 하지 않았다.

6개는 합성 사례이므로 전체 분류 정확도, 모호한 요청이나 악의적 입력에 대한 안정성은 미측정이다. 분류만으로 실행 권한을 부여하지 않으며 BE의 인증·조직 범위와 확인 절차는 별도다. 자동 테스트는 모델 응답을 대체해 타입·오류 전달을 확인했다.

GPT-5.6 Luna 실제 합성 사례 7개를 각 1회 호출했다. 지난 회의·날짜가 붙은 특정 회의·MT 행사·특정인 할 일은 모두 unsupported, 지난주 내 할 일과 10월 15일 일정은 날짜 범위를 가진 task_list, 지난 회의 회의록은 record_search였다. ## 2026-11-03 · 자료 정리·요약 분류

통합 기준 `5ea2250`에서 실제 API 단일 호출로 `행사 예산 관련 자료를 정리해줘`가 unsupported로 분류됐다. 자료 내용 조회와 내용 생성 금지 지침의 충돌 가능성은 추정이며 원인은 확정하지 못했다. 기존 자료의 정리·요약을 record_search로 명시하고 새 내용 생성·변경은 unsupported로 유지했다.

GPT-5.6 Luna, 기준일 2026-10-30, 1차 문구 변경 후 고정 사례 15개를 각 1회, 그중 신규 8개를 2회 더 호출했다. 자료 찾기·정리·요약은 각각 3/3회 record_search, 새 홍보 문구 생성·자료 수정·알림 예약도 각각 3/3회 unsupported였다. `이번 주 내 할 일 보여줘`는 task_list였으나 scope가 null인 경우 2회, AIInvalidResponseError가 1회였다. `이번 주 내 일정 보여줘`는 self/schedule 1회와 AIInvalidResponseError 2회였다. 나머지 기존 7개 사례는 각 1회 기대 결과였다. 오류 원인과 프롬프트 변경 전의 같은 반복 조건은 측정하지 않았으므로 변경에 따른 악화로 단정할 수 없다. 소수 단독 호출이며 실제 API·DB·화면 왕복이나 일반적인 정확도를 보장하지 않는다.

최종 문구는 기존 자료의 변경 금지를 더 분명하게 고친 뒤 신규 8개를 각 1회 재호출했다. 자료 찾기·정리·요약 3개는 record_search, 새 홍보 문구·자료 수정·알림 예약 3개는 unsupported, 내 할 일은 self/task였고 내 일정은 AIInvalidResponseError였다. 1차와 최종 문구 결과는 별도 측정이다.
