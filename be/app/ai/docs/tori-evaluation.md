## 2026-11-03 · 자료 정리·요약 분류

통합 기준 `5ea2250`에서 실제 API 단일 호출로 `행사 예산 관련 자료를 정리해줘`가 unsupported로 분류됐다. 자료 내용 조회와 내용 생성 금지 지침의 충돌 가능성은 추정이며 원인은 확정하지 못했다. 기존 자료의 정리·요약을 record_search로 명시하고 새 내용 생성·변경은 unsupported로 유지했다.

GPT-5.6 Luna, 기준일 2026-10-30, 1차 문구 변경 후 고정 사례 15개를 각 1회, 그중 신규 8개를 2회 더 호출했다. 자료 찾기·정리·요약은 각각 3/3회 record_search, 새 홍보 문구 생성·자료 수정·알림 예약도 각각 3/3회 unsupported였다. `이번 주 내 할 일 보여줘`는 task_list였으나 scope가 null인 경우 2회, AIInvalidResponseError가 1회였다. `이번 주 내 일정 보여줘`는 self/schedule 1회와 AIInvalidResponseError 2회였다. 나머지 기존 7개 사례는 각 1회 기대 결과였다. 오류 원인과 프롬프트 변경 전의 같은 반복 조건은 측정하지 않았으므로 변경에 따른 악화로 단정할 수 없다. 소수 단독 호출이며 실제 API·DB·화면 왕복이나 일반적인 정확도를 보장하지 않는다.

최종 문구는 기존 자료의 변경 금지를 더 분명하게 고친 뒤 신규 8개를 각 1회 재호출했다. 자료 찾기·정리·요약 3개는 record_search, 새 홍보 문구·자료 수정·알림 예약 3개는 unsupported, 내 할 일은 self/task였고 내 일정은 AIInvalidResponseError였다. 1차와 최종 문구 결과는 별도 측정이다.

## 2026-11-03 · 다행사 자료 답변 압축

기준 `724ded2`에서 합성 자료 6개(2024·2025년, 여섯 행사, 각 비용 3개)와 GPT-5.6 Luna로 단독 `answer_tori_records`를 확인했다. 기존 넓은 질문 한 번은 18개 사실을 반환했다. 수정 후보의 1차 최종 문구 6건 각 1회는 넓은 질문에 연도/전체 범위를 한 번 제시했고, 선택된 2025 봄 MT는 인용 포함 67자, 명시 질문은 58자, 전체 요약 4묶음 365자, 모호한 후속 4묶음 297자(추가 질문 없음)였다. 2024·2025 전체 비교는 항목 개요 2묶음 136자와 합계 미확인 2개였으나 수치 비교가 없어 유용성 한계가 있었다. 전체 요약에는 일부 중복도 있었다. 숫자 개수만으로 실패시키는 시도는 제거했다.

이어 같은 행사·항목의 연도별 비교값과 중복 방지 지침을 보완해 전체 요약과 전체 비교 각 1회 재호출했다. 요약은 4묶음 367자, 비교는 5묶음 399자이며 봄 MT 세 항목의 양 연도 원문 금액과 출처를 포함하고 합산값은 미확인으로 남겼다. 이 두 호출은 앞의 네 사례와 다른 프롬프트 기준이며, 하나의 반복 평가로 합치지 않는다. 후속 검색 질의도 2025년 봄 MT·전체 요약·모호한 응답을 follow_up, 이번 주 내 할 일을 new_request로 각 1회 구분했다.

모두 소수의 합성 단독 호출이며 검색 품질·실제 API/FE 왕복이나 일반적인 정확도를 뜻하지 않는다. 모델은 같은 입력에서도 다른 길이나 중복을 낼 수 있다. 같은 출처 여러 사실을 의미별로 묶어도 숫자 검증은 항목과 문장 의미의 정확성을 보장하지 않으며, 검색되지 않은 자료의 누락도 알 수 없다. 합산이나 환산은 하지 않는다.

후속 맥락 필드를 추가한 뒤 별도 실모델 검색어 3건을 각 1회 확인했다. 직전 선택지가 2024년·2025년·전체 요약일 때 '첫 번째'는 2024년 예산 검색, '전체'는 전체 요약 검색, '이번 주 내 할 일 보여줘'는 new_request였다. 이전 본문 답변 품질 측정과는 별개이며 실제 BE 재검색·화면 왕복 검증은 포함하지 않는다.
